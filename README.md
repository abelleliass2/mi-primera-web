# ¿Qué ídolo de Boca sos?

Este proyecto es una práctica grupal de desarrollo web con HTML, CSS y JavaScript.

El objetivo es crear un quiz que determine qué ídolo de Boca Juniors sos.

## Integrantes

- Elias → Fondo Bombonera y escudo PNG
- Tiziano → Programación del quiz en JavaScript
- Mateo → Estilos CSS y diseño visual
- Erik → Pruebas, depuración y documentación

## Tecnologías

- HTML
- CSS
- JavaScript
- GitHub Pages

## Cómo usar

1. Abrir `index.html` para comenzar.
2. Hacer clic en "Comenzar Quiz".
3. Responder las preguntas.
4. Ver el resultado.
